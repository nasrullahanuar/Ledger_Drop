# Ledger Drop

A browser merge-drop puzzle with an accounting theme. Drop receipts, invoices and ledgers, merge identical items, and build the Audit trophy before time runs out.

Pure HTML, CSS and JavaScript. The only dependency is [Matter.js](https://brm.io/matter-js/) (loaded from a CDN).

## Run
Open `index.html` in a browser.

## Files
- `index.html` page structure
- `style.css` visual design
- `items.js` the 12 hand-drawn items, sprites and background
- `audio.js` sound effects (Web Audio)
- `game.js` menus, difficulty, power-ups, solo and versus logic
